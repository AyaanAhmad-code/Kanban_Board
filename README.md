# 🗂️ Kanban Board – Vanilla JavaScript

A **modern, interactive Kanban Board** built from scratch using **Vanilla JavaScript**, HTML, and CSS.
This project demonstrates real-world frontend fundamentals such as **state management, drag & drop, data persistence, and clean UI design** — without using any frameworks.

> 📌 Designed to feel like an internal tool used in real teams.

---

## ✨ Features

* ✅ Create new tasks using a modal
* 🗑️ Delete tasks individually
* 🖱️ Drag & drop tasks between columns
* 💾 Persistent state using **localStorage**
* 🔢 Automatic task count per column
* 🎨 Modern dark UI with custom theme support
* 🧠 Clean, modular JavaScript logic
* ⚡ Smooth UX interactions

---

## 🧱 Kanban Columns

* **To Do** – Tasks yet to be started
* **In Progress** – Tasks currently being worked on
* **Done** – Completed tasks

---

## 🛠️ Tech Stack

* **HTML5** – Semantic structure
* **CSS3** – Custom dark theme & layout
* **JavaScript (ES6+)** – Logic & interactions
* **Browser APIs** – Drag & Drop, localStorage

## 🚀 How to Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/AyaanAhmad-code/kanban_Board.git
   ```

2. **Open the project folder**

   ```bash
   cd kanban_Board
   ```

3. **Run the app**
   Simply open `index.html` in your browser.

> No build tools or dependencies required.
